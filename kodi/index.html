IPTV Control Room for Kodi

Install in Kodi 21:

  1. Settings, System, Add-ons: turn on Unknown sources.
  2. Settings, File manager, Add source: https://adamvekony.github.io/iptv-guide/kodi/
  3. Settings, Add-ons, Install from zip file: pick that source, then the file below.
  4. Install from repository, IPTV Control Room repository, Look and feel, Skin, IPTV Control Room.
repository.iptv.controlroom.zip
skin.iptv.controlroom-1.0.5.zip
script.iptv.controlroom-1.1.2.zip

The skin and helper zips are for updating by hand (Install from zip file, helper first, then the skin) if Kodi does not pick up an update from the repository.
